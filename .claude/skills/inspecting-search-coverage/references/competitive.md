## Competitive Landscape for Church Apps

EBC Connect competes for App Store / Play Store visibility against:

| Competitor | Positioning | ASO Weakness |
|------------|------------|--------------|
| Pushpay | "Church giving + community" | Focused on payments, not community tools |
| Church Center (Planning Center) | "All-in-one church app" | Generic, large church-oriented |
| Subsplash | "Church app platform" | Platform/SaaS framing, not member-first |
| Tithe.ly | "Giving + church app" | Giving-first, community secondary |
| Generic church directories | "Church directory app" | No event/prayer integration |

EBC Connect's defensible position: **purpose-built for one church** (Edna Baptist Church). No competitor owns "Edna Baptist Church app" in the store.

## ASO Competitive Positioning

### iOS App Store — Keyword Strategy

The 100-character keyword field is not visible to users but heavily indexed:

```
church,prayer,directory,events,announcements,Baptist,community,family,EBC,Edna
```

Prioritization logic:
- `church` and `prayer` — high volume, competitive (worth including for partial match)
- `directory` and `events` — medium volume, feature-specific
- `Baptist` and `Edna` — low volume, zero competition (own this)
- `family` — medium volume, aligns with the Family tab feature

AVOID: Trademarked competitor names (violates App Store guidelines).

### Play Store — Short Description (80 chars max)

```
Church events, prayers & directory for Edna Baptist Church members.
```

This is 67 characters. It includes the primary keyword ("church"), feature keywords, and the brand-specific differentiator ("Edna Baptist Church").

## Differentiation Copy Patterns

When members share the app, the OG tags and store description are the competitive surface. Lead with what no competitor can claim:

```
// WEAK — any church app could say this
"Stay connected with your church community"

// STRONG — only EBC Connect can say this
"The official app for Edna Baptist Church — built for your church family"
```

Feature parity table to avoid mentioning in copy (competitors have these too):
- Push notifications ❌ (table stakes)
- Event calendar ❌ (table stakes)
- Mobile app ❌ (table stakes)

Features to emphasize (differentiated):
- Family groups with multi-member RSVP ✓
- Potluck coordination ✓ (niche, memorable)
- Prayer request tracking with "I prayed" confirmations ✓
- Visitor onboarding flow ✓

## App Store Review Response as SEO Signal

App Store review responses are indexed by Apple and visible in search. Respond to reviews with:
1. Church name ("Thank you from the Edna Baptist Church team")
2. Feature mentions ("Glad the prayer request feature is helpful")
3. No negative keywords in responses

## Monitoring and Benchmarking

### ASO Audit Checklist

Copy this checklist and track progress:

- [ ] Search "Edna Baptist Church" in App Store — does EBC Connect appear?
- [ ] Search "Edna Baptist Church" in Play Store — does EBC Connect appear?
- [ ] Search "church prayer app" — is EBC Connect within top 20?
- [ ] Check App Store Connect → Analytics → Source Type: "App Store Search" for keyword breakdown
- [ ] Check Play Store Console → Acquisition → Store listing → Search terms
- [ ] Verify all competitor apps to confirm none are named "EBC Connect"
- [ ] Review App Store screenshots — do they show the 3 most-used features?
- [ ] Verify long description first 3 lines are optimized (visible without "more")

### Iterate-Until-Pass Validation

1. Update App Store metadata (keywords, description, subtitle)
2. Submit for review / publish
3. Wait 48–72 hours for indexing
4. Check App Store Connect Analytics → Search Impressions
5. If target keywords show no impressions, refine keyword field and repeat step 1

See the **instrumenting-product-metrics** skill for in-app engagement metrics that correlate with store algorithm ranking (session depth, retention rate).
